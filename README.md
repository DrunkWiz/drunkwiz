## How I Build

- **Model judges, code decides** - anything touching money, dates or amounts runs in plain code
- **Degrade, don't break** - a second provider, a fallback map, offline data underneath
- **Silence beats a guess** - "amount unknown" is a valid answer
- **Tests need no network** - no API key required to run them
